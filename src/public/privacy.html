Política de privacidad

Gestor de Tareas · Última actualización: 15 de septiembre de 2026

Gestor de Tareas es una aplicación de gestión de incidencias/tareas para uso interno de una organización. Esta página explica qué datos se tratan y con qué finalidad, tanto en la versión web como en el cliente nativo de macOS.

Responsable del tratamiento

Eugenio de Frutos Sánchez. Contacto: edfrutos@gmail.com.

Qué datos se tratan

  • Cuenta: nombre de usuario, email (opcional) y contraseña (almacenada siempre cifrada con hash, nunca en texto plano).
  • Tareas/incidencias: título, descripción, categoría, prioridad, fecha límite, estado, usuario asignado y ubicación sobre un plano, introducidos por los propios usuarios de la organización.
  • Archivos adjuntos: fotografías y documentos que el usuario decide subir voluntariamente al crear o editar una tarea.
  • Datos técnicos mínimos: token de sesión y marcas de tiempo necesarios para mantener la sesión iniciada y para el registro de auditoría de cambios en cada tarea.

Qué NO se hace con estos datos

  • No se comparten con terceros ni se venden.
  • No se usan con fines publicitarios.
  • La app no incluye seguimiento (tracking) de comportamiento ni SDKs de analítica de terceros.

Dónde se almacenan

Todos los datos se guardan en un servidor propio de la organización, en una base de datos SQLite gestionada directamente por el equipo responsable de la aplicación — no en servicios de terceros ni en la nube pública.

Seguridad

Las comunicaciones entre los clientes (web y macOS) y el servidor viajan siempre cifradas por HTTPS/TLS. Las contraseñas se almacenan con hash (bcrypt), nunca en texto plano.

Conservación y derechos

Los datos se conservan mientras la cuenta permanezca activa. Cualquier usuario puede solicitar el acceso, la rectificación o la eliminación de sus datos escribiendo a edfrutos@gmail.com.

Menores de edad

Esta aplicación está pensada para uso profesional/organizativo y no está dirigida a menores de edad.

Cambios en esta política

Si esta política cambia, se actualizará esta misma página con la nueva fecha en la cabecera.
